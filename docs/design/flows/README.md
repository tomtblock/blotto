# Flow mockups

Static design mockups of the main screens, drawn in the app's visual language
(`app/src/styles/tokens.css`). **They are design mockups, not screenshots: the live app may differ.**
In particular, the battle screen shown here (a per-battle stat editor with a per-screen timer) has
been replaced by the battle board — all seven battles on one board with a single three-minute clock
(`app/src/battle/board/`). The mockups also predate the current rules: figures such as prize
splits, fill deadlines and field sizes, and the wording on them, are placeholders from an earlier
draft. The rules page (`app/src/app/rules/`) and
[`docs/guide/HOW-IT-WORKS.md`](../../guide/HOW-IT-WORKS.md) state the rules as built. Class names,
colours and pass art are placeholders too.
