# Flow mockups

Static screen mockups of every surface, rendered from the review canvas
("Blotto Cup Flows") in the app's real visual language (`app/src/styles/tokens.css`:
base `#0a0a0f`, brand `#b026ff`, Unbounded / Space Grotesk / JetBrains Mono).

The player journey, in order: play tab → pool page → age gate → battle screen
(pentagon, 15s timer, lock-current) → review + submit → class reveal →
results. Then the public verify page (R13), the read-only profile (R15), and
the founder's review desk (roadmap 4.4).

All copy is DRAFT for review — final wording is founder + counsel (Phase 6),
routed through `app/src/copy/`. Class names, colours and pass art are
founder-owned placeholders (PID D2). The editable source of these screens is
the shared review canvas; these PNGs are the committed snapshot of it.
